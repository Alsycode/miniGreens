## Style block (always paste this first)

```
A single high-fidelity mobile app screen UI for "MiniGreens" — a fresh microgreens,
cold-pressed juice and smoothie delivery app. LIGHT theme.

Colors:
- Warm off-white / cream background (#FAF7F0)
- Pure white cards with ~20px rounded corners and very soft shadows
- Deep forest green (#2F4B3A) for primary buttons, the active bottom-tab icon, and key icons
- Lively leaf green (#3E9B4F) for prices, badges and links
- Near-black green-tinted text (#1B241F); muted grey-green for secondary text

Type: elegant upright serif for headings (DM Serif Display style) + clean geometric
sans-serif for body and buttons (Plus Jakarta Sans style).

Imagery: bright, warm, high-key daylight food photography of microgreens, smoothies and
juices. No dark, moody or charcoal backgrounds.

Details: pill-shaped buttons, generous whitespace, calm and premium "fresh from the farm"
feel, realistic iOS status bar, a 5-icon bottom tab bar (Home, Shop, Orders, Learn,
Profile) with the active icon in deep green. Use short real labels, no placeholder
gibberish. Straight-on flat UI mockup.
```
